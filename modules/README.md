# Modulos

Cada carpeta documenta un modulo: proposito, archivos, entradas, salidas y evidencia para sustentar.

- `corpus/`: Corpus y preprocesamiento
- `similarity/`: Requerimiento 1: similitud textual
- `clustering/`: Requerimiento 2: clustering jerarquico
- `patterns/`: Requerimiento 3: busqueda de patrones
- `docs/`: Documentacion
